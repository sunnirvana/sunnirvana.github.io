Claude Code Cheatsheet

Claude Code

终端里的编码 agent。在仓库里跑 claude，接着上次用 -c，大改动先 /plan。当前钉在 v2.1.316。

v2.1.316 tag v2.1.316 更新于 2026-10-31

只想记一个命令

claude

在项目目录开一轮。第一次会打开浏览器登录。只要最终答案用 claude -p。

复制按钮会复制可直接贴进终端或 Claude Code 会话的命令

最短记忆

免费 claude.ai 不含 Claude Code。需要 Pro、Max、Team、Enterprise 或 Console。

先装上

macOS / Linux / WSL 用下面这条；Windows PowerShell 用 irm https://claude.ai/install.ps1 | iex。包管理器：brew install --cask claude-code，或 winget install Anthropic.ClaudeCode。

curl -fsSL https://claude.ai/install.sh | bash

登录

第一次 claude 会打开浏览器；已经决定用 ANTHROPIC_API_KEY 时会跳过。Console 按量计费加 --console。

claude auth login

在仓库里开一轮

进入项目目录再启动。会话里 /init 起草 CLAUDE.md；文件已在时只提建议，不覆盖。

claude

接着上次

claude -c 打开当前目录最近一次对话；点名用 claude -r "名字或 ID"。默认不含 claude -p 的会话。

claude -c

按场景查

先找现在要做的事，复制那一条命令。

让它记住项目约定

/init 起草项目 CLAUDE.md（./CLAUDE.md 或 ./.claude/CLAUDE.md）。个人跨项目放 ~/.claude/CLAUDE.md，单文件尽量短于 200 行。

/initCLAUDE.md
/init

先出方案，再改代码

Plan 只读代码、不改源码，直到你批准。会话里 /plan 或 Shift+Tab；启动时用下面这条。

planShift+Tab
claude --permission-mode plan

切权限模式

交互默认 auto。Shift+Tab：auto → Manual（default）→ acceptEdits → plan → 回到 auto。dontAsk 不在这个循环里，只给 claude -p。

autoacceptEdits
claude --permission-mode acceptEdits

少被问，但别放开危险命令

规则顺序 deny → ask → allow；宽的 deny 盖得住更窄的 allow，bypass 也绕不过 deny。Bash 的“不要再问”写进 .claude/settings.local.json，改文件的批准只留到这次会话结束。permissions.blockWritesOutsideWorkingDirectories 设上之后，任何权限模式下 Write、Edit、NotebookEdit 都拒绝工作目录外的路径。

/permissionsdeny
/permissions

脚本里只要最终答案

claude -p 跑完就退出。没指定模式时从 Manual 起，要批准的调用会被拒绝；CI 改成 dontAsk 并加上 --allowedTools。

-pjson
claude -p "explain this function" --output-format json

上下文满了

/compact 总结后继续同一段对话。/clear 开新对话，CLAUDE.md 还在。

/compact/clear
/compact

并行：worktree 或后台

claude -w name 在 .claude/worktrees/ 开隔离检出。整段丢到后台用 claude --bg "task"，再 claude attach <id>；不能和 -p 一起用。

-w--bg
claude -w feature-auth

接上 MCP

远程 HTTP 用下面这条。--scope project 写进仓库 .mcp.json，默认 local 只给你；密钥别提交，登录用 /mcp。

mcp.mcp.json
claude mcp add --transport http notion https://mcp.notion.com/mcp

立刻更新

原生安装会后台更新，这条立刻装当前频道（latest 或 stable）。Homebrew / WinGet 用各自的升级命令。

updatestable
claude update

坏了先诊断

claude doctor 只读，不改文件。怀疑是 CLAUDE.md、插件或 hooks，用 claude --safe-mode 先把它们关掉。

doctorsafe-mode
claude doctor

常用流程

把几条命令串起来。

第一次进一个仓库

先信任工作区。提交的项目设置要等你信任这个目录才完全生效。

cd repo && claude→/init→/permissions

大改动先出方案

批准之前不改源码。做完用 /diff 看工作区。

--permission-mode plan→批准方案→/diff

管道或 CI 里跑

精确允许名单用 dontAsk。订阅账号的长效令牌：claude setup-token，只打印、不落盘。

claude -p→--permission-mode dontAsk→--allowedTools

CLI 索引

在系统终端运行。完整列表以官方 CLI reference 为准。

命令 什么时候用 备注
claude 在当前目录开交互会话。 claude "explain this project" 带上第一条提示。
claude -p "query" 非交互，跑完退出。 --output-format text|json|stream-json。
claude -c 继续当前目录最近的对话。 默认不含 -p 会话。连那些也续上：claude -p --continue。
claude -r "name" 按 ID 或名字恢复。 不带参数则打开选择器。--fork-session 分叉出新会话。
claude update 立刻更新到当前频道。 钉 stable 或版本号用 claude install。
claude auth login 登录。 logout 登出。status --text 看是否已登录。CI 令牌：claude setup-token。
claude doctor 不启动会话的只读诊断。 要它提议并改文件，在会话里跑 /doctor。
claude --permission-mode plan 指定这一次的起点模式。 default（别名 manual）、acceptEdits、auto、dontAsk、bypassPermissions。
claude --model sonnet 这一次用哪个模型。 别名 sonnet、opus、haiku、fable。--effort high 不写入设置。子 agent 没人另外指定推理档时用 CLAUDE_CODE_SUBAGENT_EFFORT，不再继承本会话。CLAUDE_CODE_DISABLE_ULTRATHINK 关掉 ultrathink 关键字。Opus 4.8 的 fast mode 已弃用，2026-11-30 移除；之后对该模型的 fast 请求报错，且不回退到普通 Opus 4.8。要保住加速，改用 Opus 5.5。
claude --add-dir ../lib 额外授予读写目录。 默认不加载那里的 CLAUDE.md。
claude -w name 在隔离 git worktree 里启动。 路径在 .claude/worktrees/<name>。
claude --bg "task" 后台跑，马上把终端还你。 随后 claude agents、attach、logs、stop。不能和 -p 并用。
claude mcp add … 配置 MCP 服务器。 list 看状态。login <name> 走 OAuth。
claude plugin 安装和管理插件。 会话里用 /plugin。
claude --safe-mode 关掉自定义项来排障。 脚本瘦启动用 --bare。
claude --settings ./settings.json 这一次盖过同名设置键。 免询问用 --allowedTools。
claude --teleport 把云端会话拉回本机。 需要订阅。本机这一轮给手机接着控：--remote-control。
claude --version 打印已安装版本。 本页钉的上游发布是 v2.1.316。

Slash 与模式

只在消息开头生效。输入 / 看你这个账号实际有的命令。

命令 做什么 备注
/init 起草项目 CLAUDE.md。 已有文件只给建议。/memory 用来编辑说明。
/plan 进入 plan 模式。 也可 Shift+Tab。批准前不改源码。
/permissions 管理 allow / ask / deny。 别名 /allowed-tools。
/config 主题、模型等少数个人项。 别名 /settings。/status 看版本、账号、加载了哪些设置。
/model 换模型，并存成新会话默认。 选择器里按 s 只改这一次。推理档用 /effort。
/compact 总结后继续同一段对话。 /clear 开新对话。/context 看窗口被什么占满。
/rewind 把对话和/或代码退回检查点。 /diff 看工作区改动。
/mcp 连接、登录、启用或停用 MCP。 OAuth 在这里完成。
/resume 按 ID 或名字继续，或打开选择器。 别名 /continue。
/doctor 检查安装和设置，确认后才改。 终端里的 claude doctor 只读。
/btw 旁问一句，不写进对话历史。 不带问题则翻最近一次旁问。
/add-dir 这一轮额外授予一个目录。 /cd 把整个会话挪到新目录，对话保留。
/background 把当前会话拆到后台。 别名 /bg。看后台任务用 /tasks。
/usage 看用量和限额。 别名 /cost、/stats。
/plugin 插件菜单。 自写技能放 .claude/skills/<name>/SKILL.md，用 /name 调用。
/exit 离开会话。 接在后台会话上时只是 detach。登录、登出用 /login、/logout。

这些路径各管什么

同名设置键从高到低：组织托管、本次 --settings、.claude/settings.local.json、.claude/settings.json、~/.claude/settings.json。

路径 装什么 谁写
~/.claude/settings.json 这台机器上所有项目的偏好。 你，或 /config。自有设置里优先级最低。
.claude/settings.json 团队共享的权限、hooks、环境变量。 提交进 git。这里的 defaultMode: auto 不会当起点。
.claude/settings.local.json 只对你、只在这个项目。 Bash 的“不要再问”写在这里。别提交。这里的 defaultMode: auto 也不会当起点。
~/.claude.json 账号、MCP、每个项目的信任决定。 Claude Code 自己写。不用手改。
CLAUDE.md · .claude/CLAUDE.md · ~/.claude/CLAUDE.md 持久说明。越靠近启动目录越靠后。 你。/init 起草项目文件。已有 AGENTS.md 也会当项目说明读。
.claude/rules/*.md 按主题拆开的说明。 带 paths 的只在碰到匹配文件时加载。
.claude/skills/<name>/SKILL.md 用 /name 调用的流程。 个人技能放 ~/.claude/skills/。
.mcp.json 团队共享的 MCP。只在项目根。 claude mcp add --scope project。本机要批准。密钥别放这里。
.claude/worktrees/ claude -w 的隔离检出。 Claude Code 创建。
使用习惯

大改动 /plan，小改动留在 auto。权限靠 /permissions，不靠 CLAUDE.md。密钥留在 local，别进 .mcp.json。上下文满了 /compact，重来用 /clear。
