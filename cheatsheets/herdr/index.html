Herdr Cheatsheet

Herdr

关掉客户端，pane 里的工作继续跑。前缀默认 Ctrl+B，离开是前缀再按 q。当前钉在 v0.9.5。

v0.9.5 tag v0.9.5 更新于 2026-10-27

只想记一个命令

herdr

在项目目录启动，或接回已经在跑的默认会话。分离：Ctrl+B，松开，再按 q。

复制按钮会复制可直接贴进终端的命令

最短记忆

服务器握着 pane 和进程。客户端只是接上去看，分离不会停工作。

先装上

Linux / macOS 用下面这条；Windows 用 powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex"。已经用 Homebrew 就 brew install herdr。

curl -fsSL https://herdr.dev/install.sh | sh

在项目里打开

进入仓库再跑。它会启动或接上默认会话；还没有 workspace 时会自动开一个。

herdr

走了再回来

前缀再按 q，或直接关掉终端。里面的进程继续跑；再执行 herdr 接回同一场。

herdr

真要停掉这场会话

停掉服务器和 pane 里的进程。分离只卸下客户端，不会停工作。

herdr server stop

按场景查

先找现在要做的事，复制那一条命令。键位表在下面。

要另一场完全分开的运行时

先用 workspace 分开项目。要另一套 pane 和 socket 时才用命名会话，配置仍共用；停掉用 herdr session stop work。

--sessionworkspace
herdr --session work

Agent 先确认自己在 pane 里

先确认 HERDR_ENV=1，不是就停，别去控一场你不在里面的会话。给 agent 装说明：npx skills add herdrdev/herdr --skill herdr -g。

HERDR_ENVskill
test "${HERDR_ENV:-}" = 1

配置：默认可不写文件

Linux / macOS 是 ~/.config/herdr/config.toml，Windows 是 %APPDATA%\herdr\config.toml。没有文件也能跑；改完 herdr server reload-config。

config.toml--default-config
herdr --default-config

远程：SSH，或收进同一窗口

SSH 里再跑 herdr，或本机用 herdr --remote workbox 画远端。多台机器收进同一窗口用下面这条；删掉档案只断开客户端。

--remotemachine add
herdr machine add workbox

旁边再开一个 pane

只在 HERDR_ENV=1 时做。分屏默认不抢焦点；新 pane 停在空闲 shell 后再 herdr agent start reviewer --kind claude --pane <id>。

pane splitagent start
herdr pane split --current --direction right

重启后续上同一段对话

分离再接回时进程还在，不用装这个。服务器停掉再启动，Claude 要装下面这条，才会用它上报的会话续上。

integrationclaude
herdr integration install claude

更新，或改频道

herdr update 只给官方安装器：新客户端装上，兼容的旧服务器继续跑，再开一次就接上。预发布用 herdr channel set preview；Homebrew / mise / Nix 用各自的升级。

updatestable
herdr update

常用流程

键位里的 prefix 默认是 Ctrl+B。

第一次把 agent 放进去

在 pane 里照常跑你已经在用的 CLI。要在服务器重启后续上对话，再装集成。

herdr→claude→integration install claude

合上电脑，回来接着看

分离只卸下客户端。要结束进程才用 herdr server stop。

prefix+q→herdr→需要时 server stop

人在 SSH 或手机上

先普通 SSH，再在那台机器上跑 Herdr。本机想用自己的界面，改用 herdr --remote。

ssh you@server→herdr→prefix+q 后再回来

键位

默认前缀 ctrl+b：按下、松开、再按动作键。先记 prefix+c 新标签、prefix+v / prefix+minus 分屏、prefix+h/j/k/l 移动、prefix+w 进 workspace、prefix+q 分离。全部以 prefix+? 为准。

按键 做什么 备注
prefix+c 新标签。 标签是 workspace 里的另一套布局。
prefix+v / prefix+minus 向右分屏 / 向下分屏。 鼠标拖分割线也能改大小。
prefix+h/j/k/l 焦点移到左 / 下 / 上 / 右。 交换位置是 prefix+shift+h/j/k/l。
prefix+w 进入 workspace 导航。 Esc 离开。Enter 才切换。
prefix+q 分离客户端，工作继续跑。 关掉终端窗口同样是分离。
prefix+n / prefix+p 下一个 / 上一个标签。 跳到 1–9：prefix+1..9。重命名 prefix+shift+t。关闭 prefix+shift+x。
prefix+shift+n 新 workspace。 重命名 prefix+shift+w。关闭 prefix+shift+d。
prefix+z 放大当前 pane。 关闭 pane prefix+x。复制模式 prefix+[。
prefix+g 打开 Go To。 按 / 搜索。侧边栏开关是 prefix+b。
prefix+? 列出当前全部绑定。 改过键位以这里看到的为准。

CLI 索引

在系统终端运行。布局命令打 JSON，读屏命令打文本。完整列表是 herdr --help。

命令 什么时候用 备注
herdr 启动或接上默认会话。 --session <name> 指定命名会话。--remote <host> 用本机键位画远端。
herdr --version 看客户端版本。 herdr channel show 看 stable 或 preview。herdr update 按当前频道安装。
herdr status 看客户端、服务器、是否要重启。 给脚本加 --json。也有 status server 和 status client。
herdr server stop 停掉这场会话和它的 pane。 herdr server reload-config 重载可热更新的配置。
herdr session list 列出命名会话。 session attach <name> 接上。session stop 停掉一场。默认会话名叫 default。
herdr workspace list 列出 workspace。 新建：workspace create --cwd ~/project --label api。默认不抢焦点。
herdr tab list 列出标签。 tab create。不写 --workspace 时用当前 workspace。
herdr pane list 列出 pane。 分屏：pane split --current --direction right。pane run 成功只表示命令已送入。读输出：pane read <id>。
herdr agent list 列出认出来的 agent。 agent start <name> --kind claude --pane <id> 要求 pane 正停在空闲 shell。提交：agent prompt <name> "…" --wait。
herdr integration install claude 装官方集成，重启后续上会话。 codex、cursor 等把名字换掉。herdr integration status 查看。
herdr machine add workbox 把一台 SSH 机器收进同一窗口。 CLI 打到那台机器：herdr --machine workbox agent list。ID 属于那一台服务器。
herdr --default-config 打印默认 config.toml。 herdr config check 检查当前文件。herdr --help 会打出本机配置路径。
herdr --skill 打印和当前二进制匹配的 skill。 全局安装：npx skills add herdrdev/herdr --skill herdr -g。

这些路径和变量各管什么

没有配置文件也能跑。命名会话各自有运行状态，仍读同一份 config。

路径或变量 装什么 谁写
~/.config/herdr/config.toml 键位、主题、侧边栏。Windows 是 %APPDATA%\herdr\config.toml。 你。HERDR_CONFIG_PATH 可改路径。
[keys] prefix 进入前缀模式的键。默认 "ctrl+b"。 你。改完 herdr server reload-config。
HERDR_ENV / HERDR_PANE_ID / HERDR_TAB_ID / HERDR_WORKSPACE_ID HERDR_ENV=1 表示进程在 Herdr 的 pane 里。另外三个是启动时的公开 ID。 Herdr 在启动 pane 时设置。
HERDR_SESSION 给 CLI 选命名会话。日常用 --session 即可。 你，在要固定目标的脚本里。
已保存机器的档案 只存 ID、标签、SSH 目标和启用状态。密码和私钥不放这里。 herdr machine add。认证仍走 OpenSSH。
使用习惯

一个仓库一个 workspace。合盖用前缀 q，结束进程才 herdr server stop。Agent 驱动 CLI 之前先确认 HERDR_ENV=1。远程用 herdr --remote，或多台机器用 herdr machine add。
