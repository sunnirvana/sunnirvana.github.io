Herdr Cheatsheet

Herdr

编码 agent 的终端运行时。关掉客户端，pane 里的工作继续跑。当前钉在 v0.9.5（2026-10-14 发布，提交 2ecf19a）。前缀默认 Ctrl+B，离开是前缀再按 q。

v0.9.5 tag v0.9.5 更新于 2026-10-27

只想记一个命令

herdr

在项目目录启动，或接回已经在跑的默认会话。分离用 Ctrl+B，松开，再按 q。裸 herdr 会打开界面，查子命令用 herdr --help。

复制按钮会复制可直接贴进终端的命令

最短记忆

Herdr 是后台服务器加一个或多个终端客户端。服务器握着 pane 和进程；客户端只是接上去看。

先装上

Linux / macOS 用安装脚本。Windows PowerShell 用 powershell -ExecutionPolicy Bypass -c "irm https://herdr.dev/install.ps1 | iex"。新的直接安装走 stable 频道。装完新开终端，herdr --version 能打出版本号才算在 PATH 上。

curl -fsSL https://herdr.dev/install.sh | sh

在项目里打开

进入仓库再跑。它会启动或接上默认后台会话，不用自己管 socket。会话里还没有 workspace 时，Herdr 会自动开一个。一个 workspace 放一个仓库或一件事。

herdr

走了再回来

前缀再按 q，或直接关掉终端窗口。服务器和里面的 agent、测试、服务都继续跑。之后再执行 herdr，接回同一场默认会话。这是最稳的持久化：原来的进程没有停。

herdr

真要停掉这场会话

herdr server stop 停掉服务器，pane 里的进程一起停。Linux 和 macOS 上服务器会忽略 SIGHUP，关掉启动它的那个 shell 并不会停 pane；要停就用这条，或发 SIGTERM。活跃会话里，只有你确实想结束工作时才跑它。

herdr server stop

按场景查

命令和键位按 v0.9.5 文档整理。鼠标能点 pane、标签、workspace，也能拖分割线；键盘是可选的一层。

换一种安装方式

已经在用包管理器就走它：brew install herdr，或 mise use -g herdr。mise 说注册表里没有时，先升级 mise；临时可以 mise use -g github:herdrdev/herdr。Nix 用带 tag 的 flake，例如 nix profile install github:herdrdev/herdr/v0.9.5。Windows 压缩包要整目录留在一起，只拷 herdr.exe 不够。Windows ARM64 跑的是 x86_64 包的模拟。

brewmise
brew install herdr

stable，还是 preview

直接安装默认 stable。herdr channel show 看当前频道。herdr channel set preview 改去跟 master 的预发布，修得早，也可能回退；herdr channel set stable 回到稳定版。换频道会去装该频道的最新二进制，失败再跑 herdr update。Homebrew、mise、Nix 不走这个 preview 频道。已经装在 Windows preview 上的，会一直留在 preview，直到你显式切回 stable。

stablepreview
herdr channel show

更新已经装好的 Herdr

herdr update 只给 Herdr 自己的安装器用。Homebrew、mise、Nix 用各自的升级命令。默认会装上新二进制，并让仍兼容的旧服务器继续跑；客户端再开一次就接上。新的服务端能力要等那台服务器更新并重启。结束后它会列出还在旧版本上的服务器，以及各自的重启命令，并提醒你去每台已保存的 SSH 机器上再跑一次 herdr update。实验性的热切换要显式加 --handoff。

updatehandoff
herdr update

要完全分开的另一场运行时

先用 workspace 分开项目。命名会话是另一套 pane、socket 和持久状态，配置文件仍然共用。herdr session list 看名字，herdr session attach work 接上。停掉某一场用 herdr session stop work；默认会话的名字是 default。删的时候大小写要和列表里一致。给脚本加 --json。

session--json
herdr session list --json

先记这五个键

前缀默认 ctrl+b：按下，松开，再按动作键。下一键才归 Herdr，里面的 shell 和编辑器照常用自己的快捷键。prefix+c 新标签，prefix+v / prefix+minus 向右 / 向下分屏，prefix+h/j/k/l 在 pane 之间移动，prefix+w 进 workspace 导航，prefix+q 分离。随时 prefix+? 看当前生效的全部绑定，里面按 / 过滤。

ctrl+bprefix+q
prefix+?

给脚本的 JSON

workspace、tab、pane、agent 的控制命令成功时在 stdout 打 JSON，错误在 stderr、退出码 1；用法错误是 2。新建 workspace 的 ID 在 .result.workspace.workspace_id、.result.tab.tab_id、.result.root_pane.pane_id；分屏的新 pane 在 .result.pane.pane_id。公开 ID 形如 w1、w1:t1、w1:p1，关掉的不会复用。pane read 和 agent read 打的是终端文本。herdr status、herdr status server、herdr status client 默认给人读，加 --json 才是 JSON。herdr server reload-config 也回 JSON。

JSONstatus --json
herdr status --json

Agent 只在 HERDR_ENV=1 时驱动 CLI

官方 skill 的不变量：先 test "${HERDR_ENV:-}" = 1。不是 1，就说明自己不在 Herdr pane 里，然后停。外面的 agent 不要去控一场它并不拥有的会话。检查通过后，用 PATH 里的 herdr 看布局、分屏、读输出、等状态。发现命令用 herdr --help，或单独跑 herdr pane、herdr agent 这类组名；省略参数的 herdr workspace create 会真的创建。装 skill：npx skills add herdrdev/herdr --skill herdr -g。已安装的二进制用 herdr --skill 打印和这一版匹配的副本。

HERDR_ENVskill
test "${HERDR_ENV:-}" = 1

配置：默认可不写文件

Linux / macOS 读 ~/.config/herdr/config.toml，Windows 读 %APPDATA%\herdr\config.toml。herdr --help 会打出本机解析到的路径。herdr --default-config 打印完整默认配置，可重定向成起点。非法值会退回安全默认，并在启动时警告。改完用 herdr server reload-config，或界面里的 reload config。大多数界面设置不用重启 pane；只在启动时读的项仍要重启。前缀可以写成数组，例如 prefix = ["ctrl+space", "ctrl+s"]，每一项都进入同一个前缀模式。

config.toml--default-config
herdr --default-config

远程：SSH 里跑，或把机器收进同一窗口

人已经在远端 shell 里，或用手机 SSH 客户端时：ssh you@server 然后 herdr。想要本机界面去画远端会话：herdr --remote workbox（SSH config 里的 Host），本机剪贴板里的图片可以桥过去。要把本机和多台 SSH 机器放在一个窗口里：先 ssh workbox 确认能登录，再在交互终端 herdr machine add workbox。每台机器有自己的服务器；断一台不会拆掉其他台。删掉或禁用一台机器只断开客户端，远端会话继续跑。

--remotemachine add
herdr machine add workbox

CLI 打到某一台已保存的机器

侧边栏选中哪台机器，不会改你在本机 pane 里跑的 CLI 目标。远程控制加全局前缀 --machine，值是已启用档案的 ID，或唯一、区分大小写的标签。workspace / pane ID 和 agent 名字都属于那一台服务器，两台机器都可以有 w1:p1。本机 ID 和 --current 指不到远端 pane。转发不会替你安装或重启远端服务器。诊断用 herdr machine status，脚本加 --json；补 SSH 认证用 herdr machine reconnect，这一步要在你自己的终端里完成。

--machinemachine status
herdr --machine workbox agent list

侧边栏上的五种状态

blocked 是它认出了批准、提问或权限界面。working 正在跑。done 做完了、你还没看过。idle 做完或在等，而且已经被看过。CLI 用的是服务器的“已看”状态，和某一个客户端上的 Done 徽章可以不一样；两者都表示可以接收输入。unknown 是认得出 agent、但分不清单前屏幕。Antigravity 和 Grok 回到提示符就算 idle，就算它们自己的后台任务还在跑。屏幕规则认错成 idle 时，自动化仍可能把字打进批准框里；没料到的提示先看一眼。

blockedidle
herdr agent list

分离、停服务器、再启动，各留下什么

分离再接回：进程、布局、屏幕、对话都还在。服务器停掉再启动：原来的进程没了，布局（workspace、标签、pane、目录、焦点）会回来；对话要靠集成上报的会话，或 agent 自己报的 resume 命令，这项默认开着。屏幕历史默认关，因为输出里可能有密钥；要回放最近屏幕再设 [experimental] pane_history = true。各平台最多留 48 份布局快照在会话目录的 session-snapshots/，不会自动恢复。更新时，兼容的旧服务器继续跑；--handoff 才是实验性的活切换。

resumesnapshot
herdr session list --json

常用流程

把几条命令串起来。键位里的 prefix 默认是 Ctrl+B。

第一次把 agent 放进去

装好后在仓库里打开 Herdr，在 pane 里照常跑你已经在用的 CLI。它从进程和屏幕认出 agent。想在服务器重启后续上同一段对话，再装对应集成。

herdr→claude→herdr integration install claude

合上电脑，回来接着看

分离只卸下客户端。再跑一次 herdr 接回。要结束进程才用 herdr server stop。

prefix+q→herdr→需要时 server stop

人在 SSH 或手机上

先普通 SSH，再在那台机器上跑 Herdr。窄屏会改界面。本机想用自己的主题去画远端，改用 herdr --remote。

ssh you@server→herdr→prefix+q 后再 SSH 回来

pane 里的 agent 再开一个邻居

只在 HERDR_ENV=1 时做。分屏默认不抢焦点，工作目录用调用方的 $PWD。新 pane ID 从 JSON 读，再在一个空闲 shell pane 里按名字启动 agent。

pane split --current --no-focus→agent start→agent prompt --wait

键位

写法是 prefix 加下一键。默认前缀 ctrl+b。全部可改，以 prefix+? 里看到的为准。

按键 做什么 备注
prefix+c 新标签。 标签是 workspace 里的另一套布局。
prefix+v / prefix+minus 向右分屏 / 向下分屏。 鼠标拖分割线也能改大小。
prefix+h/j/k/l 焦点移到左 / 下 / 上 / 右 pane。 交换位置是 prefix+shift+h/j/k/l。
prefix+w 进入 workspace 导航。 Esc 或 Ctrl+[ 离开。跨已连接的机器时，按侧边栏顺序移动；Esc 或前缀键取消，Enter 才切换。
prefix+q 分离客户端，工作继续跑。 关掉终端窗口同样是分离。直接附着（herdr agent attach / terminal attach）里，要送出字面的 Ctrl+B，就再按一次 Ctrl+B。
prefix+n / prefix+p 下一个 / 上一个标签。 跳到 1–9：prefix+1..9。重命名 prefix+shift+t。关闭标签 prefix+shift+x。
prefix+shift+n 新 workspace。 重命名 prefix+shift+w。关闭 prefix+shift+d。
prefix+z 放大当前 pane。 关闭 pane prefix+x。进入调整大小 prefix+r。复制模式 prefix+[。
prefix+g 打开 Go To，每行一个 agent 或终端。 按 / 搜名字、种类、路径。不在搜索时，b/w/i/d 过滤 blocked / working / idle / done，a 回到全部。侧边栏开关是 prefix+b。
prefix+? 列出当前全部绑定。 多个前缀时，帮助面板会把它们都列出来。状态栏显示的是数组里的第一个。
关闭最后一个 默认会先问。 ui.confirm_close 默认 true：键位或菜单关掉 workspace 的最后一个标签，或唯一的 pane，界面会确认。普通 CLI / API 关闭仍是立刻执行。关掉确认：ui.confirm_close = false。

CLI 索引

在系统终端运行。布局和控制命令打 JSON。读屏命令打文本。权威列表是 herdr --help 和各组不带子命令时的帮助。

命令 什么时候用 备注
herdr 启动或接上默认会话。 --session <name> 指定命名会话。--remote <host> 用本机键位画远端。加 --remote-keybindings server 改用远端配置。
herdr --version 看客户端版本。 herdr channel show 打 stable 或 preview。herdr update 按当前频道安装。
herdr status --json 客户端、服务器、是否要重启，一次看完。 也有 herdr status server --json 和 herdr status client --json。不加 --json 是给人读的文本。
herdr server stop 停掉这场会话和它的 pane。 herdr server 显式跑无头服务器。herdr server reload-config 重载可热更新的配置，回 JSON。herdr server agent-manifests --json 看检测清单。
herdr session list --json 列出命名会话。 session attach <name> 接上。session stop / session delete 给脚本时加 --json。
herdr workspace list 列出 workspace，输出 JSON。 workspace create --cwd ~/project --label api --no-focus 创建且不抢焦点。关闭：workspace close <id>。主 workspace 还有挂着的 worktree 时要 --group，否则返回 workspace_group_close_required。
herdr tab list 列出标签，输出 JSON。 tab create --no-focus。不写 --workspace 时用当前 workspace。关掉一个 workspace 的最后一个标签，会把这个 workspace 也关掉。
herdr pane list 列出 pane，输出 JSON。 分屏：pane split --current --direction right --cwd "$PWD" --no-focus。在 shell 里跑命令用 pane run <id> "just test"，成功表示已经送入，不是命令已经跑完。读输出：pane read <id> --source recent-unwrapped --lines 120，这是文本。
herdr agent list 列出认出来的 agent，输出 JSON。 目标是唯一的活名字，或当前托管它的 pane ID。名字匹配 [a-z][a-z0-9_-]{0,31}。agent start reviewer --kind codex --pane <id> 要求那个 pane 正停在空闲 shell。提交：agent prompt reviewer "…" --wait --timeout 120000。已经 blocked 时会直接 agent_blocked，一个字都不送。
herdr integration install claude 装官方集成，重启后续上原生会话。 CLI reference 里的安装名还有 codex、copilot、cursor、opencode、pi、hermes、grok 等。herdr integration status 查看；--outdated-only 只留过期项。Claude Code、Codex 靠屏幕出状态；OMP 和 MastraCode 的状态要先装集成。服务器重启后续上对话，用集成上报的会话。
herdr machine list --json 列出已保存的 SSH 档案，给脚本用 JSON。 交互式 machine add 会发现远端已经在跑的会话。非交互默认 default，除非写 --remote-session。machine status <label-or-id> --json 做不提问的检查。reachable 表示这次检查时远端服务器在，不是每个打开的界面都连着。
herdr --default-config 打印默认 config.toml。 herdr config check 检查当前文件。herdr config reset-keys 备份后清掉 [keys]，回到内置 v2 键位，再 reload 或重启才生效。
herdr --skill 打印和当前二进制匹配的 skill。 全局安装：npx skills add herdrdev/herdr --skill herdr -g。仓库副本在 skills/herdr/SKILL.md。

这些路径和变量各管什么

配置全机一份。命名会话各自有运行状态，仍读同一份 config。

路径或变量 装什么 谁写
~/.config/herdr/config.toml 键位、主题、侧边栏、通知，以及终端默认值。Windows 是 %APPDATA%\herdr\config.toml。 你。没有这个文件也能跑。HERDR_CONFIG_PATH 可改路径。
[keys] prefix 进入前缀模式的键。默认 "ctrl+b"，也可以是字符串数组。 你。改完 herdr server reload-config。
[terminal] default_shell / new_cwd 新 pane 用哪个 shell，以及从哪起步。Unix 未设置时用 $SHELL，再退到 /bin/sh。Windows 优先 pwsh.exe，否则 Windows PowerShell。new_cwd = "follow" 跟着来源 pane 或 workspace。 你。已经存在的 pane 保持原来的 shell，直到重建。
[ui] mouse_capture / confirm_close 鼠标捕获默认开：Ctrl+点击由 Herdr 处理。关掉后，点标签和拖分割线也一起停，链接交给外层终端。confirm_close 默认 true。 你。看远端机器时，主题、侧边栏和键位仍用客户端这份本地配置。
HERDR_ENV / HERDR_PANE_ID / HERDR_TAB_ID / HERDR_WORKSPACE_ID HERDR_ENV=1 表示这个进程在 Herdr 管理的 pane 里。另外三个是启动时的公开 ID。pane 被移走后，进程里的这三个值不变，旧 pane ID 仍可作为别名。 Herdr 在启动 pane 进程时设置。调用方用 --env 盖不过这些名字。
HERDR_SESSION / HERDR_SOCKET_PATH 给 CLI 选命名会话，或直接指定 socket。日常用 --session 即可。 你，在需要固定目标的脚本里。
session.json · session-snapshots/ 布局和 agent 会话引用。快照最多 48 份，不含正在跑的进程，也不含屏幕历史。用 herdr session list --json 找目录。 Herdr。恢复要先停服务器，把选中的快照拷回 session.json，再启动。把它当成私人数据。
已保存机器的档案 只存不透明 ID、标签、SSH 目标和启用状态。密码、私钥、agent ticket 不放进这份目录。 herdr machine add。认证仍走 OpenSSH。
使用习惯

一个仓库一个 workspace，命名会话留给真正要隔离的运行时。合盖用前缀 q，结束进程才 herdr server stop。脚本读 JSON 里的 ID，不从侧边栏顺序猜。Agent 驱动 Herdr 之前先确认 HERDR_ENV=1。分屏加 --no-focus，除非你就是要切过去。远程自动化写 --machine，并且用那台机器自己的 ID。idle 只表示可以输入，不表示可以替它点批准。客户端更新之后，新的服务端行为要等对应服务器重启；版本不同本身不是停掉远端服务器的理由。
