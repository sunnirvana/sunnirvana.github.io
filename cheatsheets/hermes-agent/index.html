Hermes Agent Cheatsheet

Hermes Agent

Nous Research 的自改进 agent。先装好、先聊通，再叠 gateway、skills、cron。按场景查命令，复制后贴进终端或会话。

v0.20.5 tag v2026.8.19 更新于 2026-08-21 官方文档快照

只想记一个命令

hermes setup --portal

一次 OAuth 覆盖模型，以及 Tool Gateway 的 web search、生图、TTS、云浏览器。聊通之前不要叠 gateway / cron / MCP。

复制按钮会复制可直接贴进终端或 Hermes 会话的命令

最短记忆

Windows / macOS 优先用 Desktop 安装器；命令行安装后再跑 setup。

先装上

Desktop 安装器同时给 CLI 和桌面端。纯命令行：Linux/macOS/WSL 用 install.sh，Windows 原生用 install.ps1。

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

一次配好模型和工具

推荐 Nous Portal。需要自带密钥时用 hermes setup 或 hermes model。

hermes setup --portal

先聊通一轮

经典 CLI 用 hermes，推荐 TUI 用 hermes --tui。模型至少 64K 上下文。

hermes --tui

坏了先诊断

顺序：hermes doctor → hermes model → hermes setup。聊天不通时不要加功能。

hermes doctor

按场景查

先找当前要做的事，再复制对应命令。

在 Linux / macOS / WSL 安装

官方一键脚本。装完 source ~/.bashrc 或对应 shell rc。

installunix
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

换模型或加 provider

终端里跑 hermes model 才能加新 provider / 走 OAuth。会话里的 /model 只能在已配置的模型之间切。

modelprovider
hermes model

接到 Telegram / Discord / Slack

先保证 CLI 能聊。WSL 用 hermes gateway run，不要用 start。

gatewaymessaging
hermes gateway setup

它好像忘了我刚说的

USER.md / MEMORY.md 在会话开始时冻结进 system prompt。存盘立刻生效，但注入要等下一轮会话。

memorysnapshot
/new

装或用 skill

已安装 skill 会变成 /skill-name。Hub 安装会先做安全扫描。

skillshub
hermes skills browse

接着上次聊

-c 恢复最近一次会话。按标题或 ID 用 --resume。

session
hermes --continue

定时任务

跨会话、要投递到 messenger 用 hermes cron。只在当前会话空闲时叮一声，用 /heartbeat。

cronheartbeat
hermes cron

把终端关进沙箱

默认 local。Docker / SSH / Modal / Daytona 都是 terminal backend，不是另装一份 Hermes。

sandboxdocker
hermes config set terminal.backend docker

并行改同一个仓库

启动时 hermes -w，会话中 /worktree new。文件和终端工具会切到隔离 checkout。

worktree并行
hermes -w

脚本里只要最终答案

hermes -z 只把最终回复打到 stdout，无 banner / spinner。需要工具过程用 hermes chat -q。

oneshot脚本
hermes -z "Summarize this repo"

更新到最新版

--check 只预览。--backup 会在拉取前给 HERMES_HOME 做快照。

update
hermes update

让它围着一个目标继续干

Hermes 对 Ralph loop 的实现。辅助模型判断是否完成；真人消息会打断循环。

goalsession
/goal 把测试修到全绿

常用流程

把几条命令串起来，覆盖真实使用。

Windows 从零到能聊

先装，再 Portal，再用 TUI 验证一轮真实对话。

install.ps1→hermes setup --portal→hermes --tui

日常接着干

回到最近会话。换目录时加 --in。

hermes --tui --continue

做成常驻 bot

CLI 通了再接 messenger。WSL 用 foreground run。

hermes→hermes gateway setup→hermes gateway run

感觉它变笨了

先确认不是模型切错、上下文爆了、或记忆快照过期。

hermes doctor→/status→/context→hermes model

把这次流程沉淀成 skill

不必等自动回顾。会话里立刻跑 refine。

/refine 把这个部署流程存成 skill

这些文件各管什么

搞混 SOUL / USER / MEMORY / AGENTS，是“它忘了”的最常见原因。

文件 装什么 谁写
SOUL.md agent 是谁：人格、语气、风格禁忌。全局 ~/.hermes/SOUL.md。 你写。会话开始注入 slot #1。
USER.md 你是谁：名字、角色、偏好。 agent 用 memory 工具写。会话开始时冻结快照。
MEMORY.md 它学到的环境事实、项目约定、工具坑。 agent 写。同样是会话开始冻结快照。
.hermes.md / AGENTS.md 这个项目要什么。优先级：.hermes.md → AGENTS.md → CLAUDE.md → .cursorrules，只加载一种。 你（或项目作者）写。
config.yaml / .env 非密钥配置 vs 密钥。用 hermes config set 会自动分流。 你，或 setup / model 向导。

CLI 索引

在系统终端运行，不在 Hermes 会话里。权威来源是官方 CLI Commands 文档。

命令 什么时候用 备注
hermes / hermes --tui 开始聊天。TUI 是推荐界面。 --cli 可强制经典 REPL。
hermes setup --portal 最快路径：Nous 登录 + Tool Gateway。 也有 Full Setup 和 Blank Slate。
hermes model 加 provider、OAuth、改默认模型。 不要和会话里的 /model 搞混。
hermes -c / --resume 恢复最近或指定会话。 --in dir 先切目录再查会话。
hermes chat -q "…" 一次性提问，保留工具过程输出。 只要最终文本用 hermes -z。
hermes gateway setup|run|status 配置并运行 messaging gateway。 WSL 用 run，不要 start。
hermes tools 按平台开关 toolset。 单次会话也可用 --toolsets。
hermes skills browse|install 浏览 Skills Hub、安装 skill。 安装前会跑安全扫描。
hermes cron 持久定时任务。 会话内心跳用 /heartbeat。
hermes doctor 配置和依赖出问题。 排障第一步。
hermes config set … 改配置或密钥。 自动写入 yaml 或 .env。
hermes update 拉最新代码并重装依赖。 --check 预览，--backup 先快照。
hermes backup / import 整机搬家。 单 profile 用 profile export/import。
hermes dashboard 用网页管配置、密钥、会话、cron、skills。
hermes acp 把 Hermes 接到 ACP 兼容编辑器。
hermes mcp 管理 MCP server，或让 Hermes 自己当 MCP server。
hermes profile 多套隔离实例：不同模型、记忆、bot。 -p name 选 profile。
hermes kanban 多 profile 协作看板。
hermes send --to telegram "…" 脚本/cron 往 messenger 发一条，不跑 agent。
hermes sessions 浏览、导出、清理会话。

常用 slash

在 CLI / TUI / 多数 messenger 里输入 /。已安装 skill 也会出现在这个菜单里。

命令 什么时候用 典型提示
/help 看当前表面能用的命令。 /help
/model 在已配置模型之间切换。无参数打开模糊搜索 picker。 /model --global
/new [name] 开新会话。别名 /reset。加 now/-y 跳过确认。 /new my-experiment
/resume · /sessions 恢复或浏览会话。TUI 里 /sessions 是实时切换器。 /resume
/status 模型、profile、目录、token、最近工具和文件。本地计算，不打 LLM。 /status
/context [all] 上下文占用可视化。/context all 会列出 skill 和 toolset 成本。 /context all
/compress 手动压缩。/compress here 2 保留最近两轮原文。 /compress here 2
/rollback 列出或恢复文件系统 checkpoint。 /rollback 1
/diff [session] 看工作区或本会话累计 diff。 /diff session --stat
/steer 不打断当前 tool loop，等下一次 tool 结果后注入提醒。 /steer 先只改 auth 模块
/queue · /q 下一轮再问，不打断当前回复。 /q 接着写测试
/background · /btw 另开后台会话跑这件事，当前会话继续。 /btw 调研这个 API
/goal · /subgoal 跨 turn 追求一个目标，直到 judge 认为完成。 /goal 把 CI 修绿
/heartbeat 会话空闲时按间隔重新注入 prompt。最短 60s。 /heartbeat every 10m 检查部署
/refine 立刻跑记忆/skill 自改进，不必等回合结束。 /refine 把部署流程存成 skill
/yolo · /approvals 跳过或设置危险命令审批。 /approvals smart
/personality 会话级人格覆盖，不改 SOUL.md。 /personality none
/focus · /verbose 只显示最终回复，或循环工具输出详细程度。 /focus on
/worktree new CLI only。会话中切到隔离 git worktree。 /worktree new fix-auth
/handoff <platform> CLI only。把当前会话交到 messenger，要求 gateway 已运行。 /handoff telegram
/plan 捆绑 skill：打开 plan mode，计划写到 .hermes/plans/。 /plan
使用习惯

先让一次普通聊天跑通，再叠加 gateway、cron、MCP。改 SOUL.md / AGENTS.md 或刚写入的记忆，要新开会话才进入 system prompt。hermes model 负责加 provider，/model 只负责已经配好的模型。
