Hermes Agent Cheatsheet

Hermes Agent

Nous Research 的自改进 agent。先装好、先聊通，再叠 gateway、Bot Mode、skills、cron。v0.22.0「Threshold Release」是 0.21 之后最大的一版，并收编 0.21.1–0.21.7 的 patch；v0.22.2 是 0.22 线当前正式版（0.22.1 打错了提交，已被 0.22.2 取代）。这一版的主线：全新桌面安装先进引导聊天（免费试用模型 nous/welcome，不用 key）；Connectors 让 agent 直接在 Linear、Notion 等应用里干活；本地模型一键跑（自动装 llama.cpp）；源码安装默认跟测试过的 SemVer 稳定版；桌面端改为签名包，底层统一由 hermes pm 管依赖；一台机器只跑一个 gateway 和一个桌面后端，服务所有 profile。升级前先看「从 0.21 升到 0.22」卡片：Python 3.14、Windows 只剩 MSIX、消息平台不再按空闲/每日自动重置会话、90 天未活跃的已结束会话默认自动清理。

最短记忆

Windows / macOS 优先 Desktop；命令行装完再 setup。会话存在 ~/.hermes/state.db。0.22 起每台机器只跑一个 gateway 和一个桌面后端，服务所有 profile；新建 profile 不用重启，它的 bot 立刻上线，凭证、白名单、cron 与会话仍按 profile 隔离。

先装上

0.22 起 Desktop 是签名包，自带 Python 和 Node，自己更新，首次启动不再现场构建：Windows 用 MSIX（x64 / ARM64，需 Windows 11 22H2+，可走 Microsoft Store 或 App Installer），macOS 默认只出 Apple Silicon 版。纯命令行：Linux/macOS/WSL 用 install.sh，Windows 原生用 install.ps1；安装器会先校验 uv 和 Git 的哈希，再交给包管理器 hermes pm，日志在 logs/install.log。

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

一次配好模型和工具

推荐 Nous Portal。OpenRouter 可用 hermes auth add openrouter --type oauth（PKCE 代发密钥）。会话里也可用 /login 补登。0.22：全新桌面安装会先开一段引导聊天（名字、配色、布局、要连的应用和插件），跑在免费试用模型 nous/welcome 上（每个系统用户一次），不用 key；Skip setup 跳过，Settings → Run onboarding again 重来。CLI / TUI / gateway 没有这个免费模型。

hermes setup --portal

先聊通一轮

经典 CLI 用 hermes，推荐 TUI 用 hermes --tui。模型至少 64K 上下文。每个模型 picker 都可设 reasoning effort（minimal…ultra / Disable / Skip），0.22 也可一步写成 /model X --reasoning high。

hermes --tui

坏了先诊断

顺序：hermes doctor →（会话库）hermes sessions recover --inspect-only → hermes model。gateway 在跑时不要 doctor --fix；跨 VM 文件系统上 WAL 会被拒绝。0.22 起托管的依赖环境另用 hermes pm doctor 查、hermes pm repair 修。

按场景查

先找当前要做的事，再复制对应命令。v0.22.0 是带完整说明的大版本（收编并补全 0.21.1–0.21.7），0.22.2 是它的修正版；下面把 0.21.7→0.22.2 操作者会摸到的变化折进各张卡片。

在 Linux / macOS / WSL 安装

官方一键脚本。装完 source ~/.bashrc 或对应 shell rc。0.22 起 musl Linux（Alpine、Void）也能装，托管安装的运行时是 Python 3.14（由 hermes pm 自动装）。已有安装用 hermes update，默认跟最新稳定版。Docker / Cloud 镜像跟 nousresearch/hermes-agent:stable（tag 形如 v0.22.2）；0.22 起基础镜像钉在 Debian 13 并带完整 Chromium，stable / latest 只在正式发布时移动。

换模型或加 provider

终端跑 hermes model / hermes auth 才能加 provider。保存模型后会跟一步 reasoning effort。OpenRouter：hermes auth add openrouter --type oauth。会话里 /model 只切已配置模型。0.22：picker 可给常用模型加星，直接显示订阅余量（如「17% left · resets 3:00 PM」）和限流何时解除；新进 Claude Opus / Sonnet / Haiku 5.5、GPT-6 Astra / Sol / Luna、Gemini 4 Argon、DeepSeek V4.1 Flash 等。provider 抽风（503 / 529 / 超时）时会按 agent.auto_recovery_cycles（默认 5）可见地等待重试，不再直接结束回合；自动路由不会悄悄计费到你没选的 provider。

不要 key、不出网：一键本地模型

0.22：Hermes 自动安装并维护 llama.cpp，按硬件选 CPU / CUDA / Metal / Vulkan / ROCm 引擎，按你的显存和内存给目录里每个模型打分，只推荐能完整放进 GPU 的版本；下载可暂停续传，服务随 Hermes 启停，引擎更新一键完成。目录含 Qwen3.8 27B、Qwen3.8 Flash Next、Qwen3.6 35B-A3B、DeepSeek V4 Flash，也能拉任意 Hugging Face GGUF。桌面端在 Settings → Providers → Local Models。LM Studio、Ollama 和自己起的 llama.cpp server 也能在 /model 里选。0.22.2：本地长回合在笔记本上不再因睡眠或读长 prompt 而超时中断，状态栏会显示读 prompt 的进度。

Connectors：让它在你的应用里干活

0.22：通过 Nous tool gateway 直接操作 Linear、Notion 等托管应用：开口要一个应用，在浏览器里登录一次，同一回合就能用上它的工具。起步不需要 Nous 账号，第一次用时会建一个只用于 connectors 的免费身份；之后 hermes auth upgrade 或在会话里 /login 升级成完整账号，已连的应用保留。桌面新的 Connectors 页把托管应用和你的 MCP server 放在同一列表（取代原 MCP 标签）；同一应用可连多个具名账号（如 work / home），用 /connectors 或 hermes connectors 管理。不想要：tools.connectors.enabled: false；关掉免费身份：nous.guest: false。Desktop 想少打扰仍可切 Simple 模式。

state.db 报错 / 会话列表挂了

先停 gateway，再 doctor；结构损坏用 recover（不改源库）。跨 VM / 共享盘要把 WAL 换成 rollback journal 时用 hermes sessions set-journal-mode delete（先停所有占用进程）。0.22：锁超时会点名持有锁的进程，数据库忙不再直接杀掉回合；profile 串了用 hermes sessions repair-profiles。sessions.auto_prune 默认开启，启动时删除 90 天未活跃的已结束会话（置顶和打开的不动；要全留设 false）。0.22.2 已知问题：在 0.22.1 gateway 下跑过的会话，在 0.22.2 里删不掉。

Bot Mode / 让 bot 互聊

Desktop 内置 Bot Mode。0.22 起一台机器一个 gateway 服务所有 profile：hermes update 会把旧的每 profile gateway 自动合并（无冲突时），也可手动 hermes gateway migrate --multiplex；只停一个 profile 用 hermes -p X gateway stop；webhook 平台按 /p/<profile>/ 分路径。Bot Screen：Linux gateway 上的 bot 可以有自己的桌面，Desktop 实时串流，碰到登录、2FA 或验证码时你接管、做完再交还（默认关闭，需要主机装包）。临时豁免仍是 gateway.standalone: true。跨机 bot DM 用 hermes peer。

装 skill / plugin / MCP

已安装 skill 会变成 /skill-name。要用同一批 skill 开每个新会话：在 config.yaml 设 skills.auto_load。插件走 hermes plugins；0.22 的插件目录有 600 个经审核插件，每个钉在审核过的提交上，Desktop 或 CLI 一键装，有已知问题的安装时会提示。hermes sync（Skill Sync）和内置 tirith 扫描已移除；curator 30 天未用的 skill 会归档（原为 90 天）。MCP 同时连接数用 mcp.discovery_concurrency（默认 4）；OAuth 过期 hermes mcp login <server>，无头终端加 --flow device。

cron 会加载持久记忆；可开 continuity、每任务 notepad、monitor 模式；时区按 IANA，跨 DST 不漂。0.22：没钉模型的任务在触发时跟随你当前的主模型（要锁定就 pinned）；没送达模型的触发（如机器刚醒）会在 5 / 15 / 30 分钟后重跑；失败告警每次事故只发一条；--paused 建任务但先不启用；agent 可输出 [CRON_FAILURE] 主动判失败。会话内心跳仍用 /heartbeat。

源码安装选更新频道

0.22 起每个稳定版发布前都要过源码 CI、Docker、Nix、签名桌面构建，以及各系统的安装 / 升级测试；官方仓库的源码安装默认从一个 release 走到下一个，不再追 main 上的每个提交。要继续追每个提交：hermes update --set-channel main，或 Desktop Settings ▸ About 里的频道开关（Stable / Every commit）。回到更旧的版本会标成 rollback，必须你确认；重跑安装器会保持你选的频道。已经比最新 release 新的安装停在原地等下一个。fork 仍跟 main。更新检查改成每天一次 GitHub API 调用（原为每 30 分钟 git fetch）。签名包（MSIX / Store / macOS）里 hermes update 会指向对应的系统更新器。

channelstable
hermes update --set-channel main

更新到最新版

--check / --plan 只预览。--backup 拉取前给 HERMES_HOME 快照。Cloud / Docker：拉 nousresearch/hermes-agent:stable（或 :latest）；镜像安装会拒绝原地 hermes update；Microsoft Store 版走 Store 更新。0.22：更新会先建一套新的依赖环境，自检通过才切换，所以失败或被杀掉的更新不会半途生效，下次启动会自修复；只重建改动的部分，更快；旧环境用 hermes pm gc 回收。0.22.2：修掉了系统重启后 gateway 把被复用的 PID 当成自己、拒绝启动的问题（systemd / launchd / Docker 托管尤其会碰到）；装了 0.22.1 的跑一次 hermes update 就回到正式发布线。防火墙后更新检查失败时，先 gh auth login 或设置 GITHUB_TOKEN。

update
hermes update

从 0.21 升到 0.22 先看这几条

托管安装的运行时变成 Python 3.14（包管理器自动装；KittenTTS 在 3.14 上不可用）。Windows 桌面只剩 MSIX、需要 Windows 11 22H2 或更新，旧 NSIS / MSI 安装器取消；macOS 默认只出 Apple Silicon 版。每 profile 一个的 gateway 会被合并成一台机器一个。消息平台不再按空闲 / 每日自动重置会话。sessions.auto_prune 默认开（90 天未活跃的已结束会话会被删）。外部 memory provider 和 Home Assistant、Spotify、Langfuse 改成插件目录里的插件，自动迁移。工具改名 todo → todo_list、cronjob → cronjob_manage、process → process_manage（旧名仍可用）。hermes sync 与内置 tirith 已移除；插件旧的兼容导入层也删了。

这些文件各管什么

搞混 SOUL / USER / MEMORY / AGENTS / state.db，是“它忘了”和“会话丢了”的最常见原因。

文件 装什么 谁写
SOUL.md agent 是谁：人格、语气、风格禁忌。全局 ~/.hermes/SOUL.md。 你写。会话开始注入；改后需新会话。
memories/USER.md 你是谁：名字、角色、偏好。路径 ~/.hermes/memories/USER.md。 agent 用 memory 工具写。会话开始冻结快照。
memories/MEMORY.md 它学到的环境事实、项目约定、工具坑。 agent 写。同样会话开始冻结；跨会话细节靠 session_search。0.22 起手写格式也能被接受，写给外部 provider 前会先清掉密钥。
.hermes.md / AGENTS.md 这个项目要什么。优先级：.hermes.md → AGENTS.md → CLAUDE.md → .cursorrules，只加载一种。 你写。v0.21 起对 instruction/skills/memory 写操作常需审批。0.22：/context 会逐个显示每个指令文件是已加载、被截断还是被遮蔽。
state.db 会话元数据 + 全文消息 + FTS5。默认 ~/.hermes/state.db（WAL）。每 profile 隔离。写者共享句柄；跨 VM 盘用 sessions set-journal-mode 切 DELETE，勿直接 cp 拆开 -wal/-shm。0.22 起默认自动清理 90 天未活跃的已结束会话，只有可回收空间达 25% 才 VACUUM。 runtime 写。损坏时用 doctor / sessions recover|repair。
shared-state.db 托管房间等跨 profile 共享状态。v0.21.2 起不再每 5 秒写进根 state.db，避免第二写者撕锁。 gateway / Bot Mode 写。
mcp-tokens/*.json MCP OAuth 令牌缓存（0o600）。refresh 绑定签发 issuer；issuer 变了会丢 refresh 并要求重授权。 hermes mcp login / Desktop Authorize。
config.yaml / .env 非密钥配置 vs 密钥。含 agent.reasoning_effort、skills.auto_load、mcp.discovery_concurrency、gateway.standalone、unauthorized_dm_behavior，0.22 新增 sessions.auto_prune、tools.connectors.enabled、agent.auto_recovery_cycles、agent.turn_liveness.timeout_s。用 hermes config set 自动分流；0.22 起 config.yaml 坏了会回退到上一份好的。 你，或 setup / model / auth 向导。

CLI 索引

在系统终端运行，不在 Hermes 会话里。权威来源是 官方 CLI Commands。

命令 什么时候用 备注
hermes / hermes --tui 开始聊天。TUI 是推荐界面。 --cli 强制经典 REPL；Ctrl+P 命令面板。
hermes setup --portal 最快路径：Nous 登录 + Tool Gateway。 也有 Full Setup 和 Blank Slate。
hermes model · hermes auth 加 provider、OAuth、改默认模型；管凭据池。模型保存后跟 reasoning effort 步。 OpenRouter：auth add openrouter --type oauth。0.22：hermes model 里有 Local models；hermes auth upgrade 把免费身份升级成完整 Nous 账号。不要和会话里的 /model、/login 搞混。
hermes -c / --resume 恢复最近或指定会话。 --in dir 先切目录再查会话。0.22 起推理默认跨恢复、分支和压缩回放。
hermes chat -q "…" · hermes -z 提问。TTY 上 -q 默认种交互会话；纯一次性用 -z / --oneshot；机器可读进度加 --format stream-json。 stream-json 隐含 quiet，不可与 --tui 并用。0.22：-z 失败返回非零退出码。
hermes gateway setup|run|status 配置并运行 messaging gateway；0.22 起一台机器一个 gateway 服务所有 profile，单 profile 用 hermes -p X gateway stop|start。 WSL 用 run。status 会说明启动保护为什么拒绝；手动合并用 gateway migrate --multiplex；临时独立网关 gateway.standalone: true（将移除）。0.22.2 修了重启后误判 PID 不启动。
hermes sessions … list / export / prune / pin / optimize / repair / recover / set-journal-mode，0.22 加 repair-profiles、repair-prompts。 recover 离线重建到新文件；改 journal 前先停占用进程。健康拓扑不应误报多写者。
hermes peer add|dm|run|status 注册对端 gateway，向对方 Bot Chat 发 DM / 长任务。 跨机 bot-to-bot 传输层。
hermes plugins 装/启停插件、memory provider、model provider、context engine；0.22 目录 600 个审核插件，各钉一个审核过的提交。 无子命令进入交互屏；search / pack install。
hermes tools 按平台开关 toolset。 单次会话也可用 --toolsets。
hermes skills browse|install 浏览 Skills Hub、安装 skill；会话常驻用 skills.auto_load。 安装前会跑安全扫描；缺/禁用的 auto_load 名会跳过并打警告。
hermes cron 持久定时任务；含 memory / continuity / monitor / notepad。 会话内心跳用 /heartbeat；时区按 IANA；cron doctor 查舰队健康。
hermes doctor [--fix] 配置、依赖、会话库健康。 gateway 在跑时勿 --fix；会区分结构损坏 vs FTS。
hermes config set … 改配置或密钥。 自动写入 yaml 或 .env。
hermes update 按更新频道拉代码并重装依赖。 官方源码安装默认跟最新稳定版；追每个提交用 --set-channel main。--check / --plan 预览，--backup 先快照；镜像安装拒绝原地更新。0.22 起新环境自检通过才切换，不会半途生效。
hermes backup / import 整机搬家；默认保留最近 3 个 zip。 单 profile 用 profile export/import；*.db 按页导入，勿改 inode。
hermes secrets 外部密钥源（如 Bitwarden Secrets Manager）。 配合密码盲填 / egress。
hermes approvals 从审批历史挖 allowlist 提案。 危险命令 / 受保护文件写入相关。
hermes security audit 对 venv、插件依赖、钉扎 MCP 做 OSV 扫描。 不扫全局包。
hermes dashboard 用网页管配置、密钥、会话、cron、skills、MCP/Connectors。 优先只读打开会话库；刷新 token 合并仍在；Desktop 侧 MCP 标签已换成 Connectors。
hermes mcp · mcp login 管理 MCP server，或让 Hermes 自己当 MCP server；过期 OAuth 重授权。 refresh 绑定 issuer；Desktop 有每日重授权提醒。0.22：无头终端用 mcp login <server> --flow device；-t 可挑启动哪些 MCP server。
hermes profile · -p name 多套隔离实例：不同模型、记忆、bot、state.db。 主机网关单例；可对单 profile 停/启/重启。勿新建依赖 gateway.standalone 的拓扑。
hermes kanban 多 profile 协作看板。 promote 会拒未完成父任务。0.22：kanban edit --title/--body/--priority、create --body-file。
hermes send --to telegram "…" 脚本/cron 往 messenger 发一条，不跑 agent。 0.22：WhatsApp 原生 @ 用 --mention。
hermes connectors 0.22：管理托管应用连接（Linear、Notion 等）和多个具名账号。 会话里同义命令 /connectors；关闭用 tools.connectors.enabled: false。
hermes pm doctor|status|repair|gc 0.22：统一包管理器，管钉扎且校验哈希的 Python 3.14、uv、Node、ripgrep、FFmpeg、Chromium 等。 依赖环境按代切换；gc 回收旧环境。贡献者用 source ./activate。
hermes usage --json 0.22：脚本里查配额，不开会话。
hermes --native 0.22：让你自己的终端接管 TUI 的回滚和搜索（也可 display.tui_native）。 同期可选：display.vim_mode、display.bell_on_prompt、状态栏 git 分支，默认都关。
hermes acp · desktop · serve 接到 ACP 编辑器；启动 Desktop；无头后端服务。 长驻 serve/dashboard 共享 state.db 写柄注册表，避免重复 writer。

常用 slash

在 CLI / TUI / 多数 messenger 里输入 /。已安装 skill 也会出现在这个菜单里。权威：Slash Commands。

命令 什么时候用 典型提示
/help · /palette 看可用命令；模糊命令面板（也可用 Ctrl+P）。选中只插入，不自动执行。 /palette
/login 会话内登 Nous。离回合：链接与码进会话，浏览器确认后生效。群聊会拒绝；Slack 用 /hermes login。0.22：免费身份用户在 DM 里 /login 升级成完整账号。 /login
/model 在已配置模型之间切换。无参数打开模糊搜索 picker；可一步带 reasoning effort。0.22：大会话里换模型会破坏提示缓存时先确认。 /model X --reasoning high
/new [name] 开新会话。别名 /reset。加 now/-y 跳过确认。记忆快照在此刻重读。0.22 起消息平台不再自动按空闲/每日重置，只有它开新会话。 /new my-experiment
/resume · /sessions 恢复或浏览会话。TUI 里 /sessions 是实时切换器。 /resume
/status 模型、profile、目录、token、reasoning、待审批、上下文占用 + 本地 Session recap。不打 LLM。 /status
/context [all] 上下文占用可视化。/context all 会列出 skill 和 toolset 成本；0.22 起逐个显示指令文件已加载 / 截断 / 遮蔽。 /context all
/compress 手动压缩。/compress here 2 保留最近两轮原文。默认 lean-tail。 /compress here 2
/rollback 列出或恢复文件系统 checkpoint。 /rollback 1
/diff [session] 看工作区或本会话累计 diff。 /diff session --stat
/steer 不打断当前 tool loop；下一次 tool 结果后注入提醒。也可用于纠偏子代理航向。0.22 简写 /s。 /steer 先只改 auth 模块
/queue · /q 下一轮再问，不打断当前回复。0.22 起可列出、编辑、移动或删除排队的提示。 /q 接着写测试
/stop 停掉当前回合；0.22 起也能停后台子代理，并把它们已完成的部分交回来。 /stop
/connectors 0.22：查看和管理已连的托管应用与账号；新应用直接在对话里要即可。 /connectors
/branch 0.22：在 Discord / Telegram / Slack / Matrix 上开一个兄弟线程继续；--here 保留原地分支的旧行为。 /branch 试另一个方案
/background · /btw 另开后台会话跑这件事，当前会话继续。 /btw 调研这个 API
/goal · /subgoal 跨 turn 追求一个目标，直到 judge 认为完成。 /goal 把 CI 修绿
/heartbeat 会话空闲时按间隔重新注入 prompt。最短 60s。 /heartbeat every 10m 检查部署
/refine 立刻跑记忆/skill 自改进，不必等回合结束。 /refine 把部署流程存成 skill
/yolo · /approvals 跳过或设置危险命令审批。 /approvals smart
/personality 会话级人格覆盖，不改 SOUL.md。 /personality none
/focus · /verbose · /statusbar 只显示最终回复；工具输出详细程度；状态栏（缓存命中/延迟等）。 /focus on
/plugins · /reload-mcp 会话里管插件；重载 MCP（CLI 侧）。OAuth 过期后需先 mcp login 再 reload。 /reload-mcp
/worktree new CLI only。会话中切到隔离 git worktree。 /worktree new fix-auth
/handoff <platform> CLI only。把当前会话交到 messenger，要求 gateway 已运行。 /handoff telegram
/plan 捆绑 skill：打开 plan mode，计划写到 .hermes/plans/。 /plan
使用习惯

先让一次普通聊天跑通，再叠加 gateway、Bot Mode、cron、MCP/Connectors。改 SOUL.md / AGENTS.md 或刚写入的记忆，要新开会话才进入 system prompt；skills.auto_load 也在下一会话生效。hermes model / hermes auth 加 provider；/model 只切已配模型。多 profile 的 state.db 隔离。gateway 在跑时不要 doctor --fix 或拆开复制 WAL。脚本集成优先 --format stream-json。Desktop 想少打扰用 Simple；连应用和 MCP 都在 Connectors。升到 0.22 后不想自动清理老会话，记得设 sessions.auto_prune: false。
