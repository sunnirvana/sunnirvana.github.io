Hermes Agent Cheatsheet

Hermes Agent

Nous Research 的自改进 agent。先装好、先聊通，再叠 gateway、Bot Mode、skills、cron。v0.21.3 重点修了 Desktop/Cloud 刷新会话与长驻进程的 state.db 写柄泄漏；会话库异常仍先 doctor / recover。

v0.21.3 tag v2026.9.14 更新于 2026-09-15

只想记一个命令

hermes setup --portal

一次 OAuth 覆盖模型与 Tool Gateway。聊通之前不要叠 gateway / cron / MCP。Desktop 远程看板醒来连刷不再误踢会话；state.db 异常先跑 doctor。

复制按钮会复制可直接贴进终端或 Hermes 会话的命令

最短记忆

Windows / macOS 优先 Desktop；命令行装完再 setup。会话存在 ~/.hermes/state.db。0.21.3 起读写柄按进程内注册表共享，健康拓扑不应再刷「N live SessionDB handles」。

先装上

Desktop 安装器同时给 CLI 和桌面端。纯命令行：Linux/macOS/WSL 用 install.sh，Windows 原生用 install.ps1（可捆绑 MinGit）。

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

一次配好模型和工具

推荐 Nous Portal。OpenRouter 可用 hermes auth add openrouter --type oauth（PKCE 代发密钥）。会话里也可用 /login 补登。

hermes setup --portal

先聊通一轮

经典 CLI 用 hermes，推荐 TUI 用 hermes --tui。模型至少 64K 上下文。每个模型 picker 都可设 reasoning effort（minimal…ultra / Disable / Skip）。

hermes --tui

坏了先诊断

顺序：hermes doctor →（会话库）hermes sessions recover --inspect-only → hermes model。gateway 在跑时不要 doctor --fix；跨 VM 文件系统上 WAL 会被拒绝。

hermes doctor

按场景查

先找当前要做的事，再复制对应命令。0.21.3 是 patch rollup；完整功能笔记留给 v0.22.0，下面只收操作者会摸到的增量。

在 Linux / macOS / WSL 安装

官方一键脚本。装完 source ~/.bashrc 或对应 shell rc。已有安装用 hermes update；Docker 镜像跟 tag v2026.9.14。

installunix
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

换模型或加 provider

终端跑 hermes model / hermes auth 才能加 provider。保存模型后会跟一步 reasoning effort。OpenRouter：hermes auth add openrouter --type oauth。会话里 /model 只切已配置模型。

modelreasoning
hermes model

接到 Telegram / Discord / Slack

先保证 CLI 能聊。WSL / Docker / Termux 用 hermes gateway run，不要用 start。也支持 Signal、WhatsApp 等；Slack 可贴表格。

gatewaymessaging
hermes gateway setup

Desktop / Cloud 看板刷新后掉线

v0.21.3：gateway 的 cookie / bearer 刷新路径会合并同一 rotating refresh token 的并发请求，Desktop 醒来连刷不再把已旋转 token 打进 Portal 复用检测从而整段踢下线。慢 IDP 也不再卡死 /api/status。

desktoprefresh
hermes update

state.db 报错 / 会话列表挂了

先停 gateway，再 doctor；结构损坏用 recover（不改源库）。0.21.3：gateway / dashboard / ACP / CLI 读者只读挂载，进程内写者共享注册表句柄，健康拓扑不应再漏出重复 writer。跨 VM 文件系统会拒绝 WAL。

state.dbrecover
hermes sessions recover --source ~/.hermes/state.db --inspect-only

它好像忘了我刚说的

~/.hermes/memories/USER.md / MEMORY.md 在会话开始冻结进 system prompt。存盘立刻生效，注入要等 /new。跨会话回忆靠 FTS session_search。

memorysnapshot
/new

Bot Mode / 让 bot 互聊

Desktop 内置 Bot Mode：多 profile 有名字与头像，可建群聊。跨机 bot DM 用 hermes peer。multiplex 下凭证、白名单、cwd、cron、MCP 按 profile 隔离；served profile 都会进网关。

bot-modemultiplex
hermes peer list

装 skill / plugin / MCP

已安装 skill 会变成 /skill-name。插件走 hermes plugins（目录 SHA 钉扎）。MCP OAuth refresh token 绑定签发 issuer，issuer 变更会丢弃旧 refresh；Desktop 有每日 MCP 重授权提醒，过期用 hermes mcp login <server>。

skillsmcp
hermes plugins

接着上次聊

-c 恢复最近会话；按标题/ID 用 --resume。重要会话可 hermes sessions pin。脚本续跑：hermes -z --resume …。

sessionpin
hermes --continue

定时任务（会记住上次）

cron 会加载持久记忆；可开 continuity、每任务 notepad、monitor 模式。0.21.3：croniter 锚定配置的 IANA 时区，跨 DST 不再漂。会话内心跳仍用 /heartbeat。

cronDST
hermes cron

把终端关进沙箱

默认 local。另有 Docker / SSH / Singularity / Modal / Daytona / Vercel Sandbox。Docker 可再配 hermes egress 注入凭据。state.db 不要放在跨 VM 共享盘上开 WAL。

sandboxdocker
hermes config set terminal.backend docker

并行改仓库 / 管子代理

启动 hermes -w 或会话中 /worktree new。子代理可中途 /steer 纠偏；delegation 的 effort 可选 Inherit parent。

worktreesteer
hermes -w

脚本里只要最终答案

hermes -z 只把最终回复打到 stdout。chat -q 在 TTY 会种下一轮交互；纯一次性加 --oneshot / -Q。可加 --usage-file。

oneshot脚本
hermes -z "Summarize this repo"

更新到最新版

--check / --plan 只预览。--backup 拉取前给 HERMES_HOME 快照。Cloud / Docker：拉 nousresearch/hermes-agent:v2026.9.14；镜像安装会拒绝原地 hermes update。

update
hermes update

密钥与受保护写入

密码盲填：1Password / Bitwarden / 本地 vault，agent 可不看见明文。写 AGENTS.md / skills / memory 常需审批；可用 hermes approvals 挖白名单。

secretsapprovals
hermes secrets

让它围着一个目标继续干

Hermes 对 Ralph loop 的实现。辅助模型判断是否完成；真人消息会打断循环。

goalsession
/goal 把测试修到全绿

常用流程

把几条命令串起来，覆盖真实使用。

Windows 从零到能聊

先装，再 Portal，再用 TUI 验证一轮真实对话。

install.ps1→hermes setup --portal→hermes --tui

日常接着干

回到最近会话。换目录时加 --in。会话中 Ctrl+P / /palette 找命令；换模型后可调 reasoning effort。

hermes --tui --continue

做成常驻 bot

CLI 通了再接 messenger。WSL 用 foreground run。

hermes→hermes gateway setup→hermes gateway run

远程 Desktop 总被刷掉登录

升到 0.21.3 / v2026.9.14 后，刷新 token 合并会消掉醒来连刷的误踢。Cloud 镜像跟同一 tag。

hermes update→重启 Desktop / dashboard→再连远程看板

会话库坏了（0.21.x）

先停 gateway，再 doctor 区分结构损坏 vs FTS。recover 只写到新库。若刷「N live SessionDB handles」且拓扑健康，先确认已升到 0.21.3 的句柄注册表修复。

hermes gateway stop→hermes doctor→sessions recover --inspect-only→recover --output …

感觉它变笨了

先确认不是模型切错、上下文爆了、或记忆快照过期。

hermes doctor→/status→/context→hermes model

跨机让两个 bot 交接

对端开 API server，本机注册 peer，再 DM 到对方 Bot Chat。

hermes peer add …→hermes peer dm name "…"

把这次流程沉淀成 skill

不必等自动回顾。会话里立刻跑 refine；MCP 过期先 hermes mcp login，插件用 catalog 钉扎安装。

/refine 把这个部署流程存成 skill

这些文件各管什么

搞混 SOUL / USER / MEMORY / AGENTS / state.db，是“它忘了”和“会话丢了”的最常见原因。

文件 装什么 谁写
SOUL.md agent 是谁：人格、语气、风格禁忌。全局 ~/.hermes/SOUL.md。 你写。会话开始注入；改后需新会话。
memories/USER.md 你是谁：名字、角色、偏好。路径 ~/.hermes/memories/USER.md。 agent 用 memory 工具写。会话开始冻结快照。
memories/MEMORY.md 它学到的环境事实、项目约定、工具坑。 agent 写。同样会话开始冻结；跨会话细节靠 session_search。
.hermes.md / AGENTS.md 这个项目要什么。优先级：.hermes.md → AGENTS.md → CLAUDE.md → .cursorrules，只加载一种。 你写。v0.21 起对 instruction/skills/memory 写操作常需审批。
state.db 会话元数据 + 全文消息 + FTS5。默认 ~/.hermes/state.db（WAL）。每 profile 隔离。0.21.3：进程内写者共享句柄，读者只读；勿放跨 VM 盘。 runtime 写。损坏时用 doctor / sessions recover|repair，勿随便 cp 拆开 -wal/-shm。
shared-state.db 托管房间等跨 profile 共享状态。v0.21.2 起不再每 5 秒写进根 state.db，避免第二写者撕锁。 gateway / Bot Mode 写。
mcp-tokens/*.json MCP OAuth 令牌缓存（0o600）。refresh 绑定签发 issuer；issuer 变了会丢 refresh 并要求重授权。 hermes mcp login / Desktop Authorize。
config.yaml / .env 非密钥配置 vs 密钥。含 agent.reasoning_effort 与各 auxiliary effort。用 hermes config set 会自动分流；备份在 backups/config/。 你，或 setup / model / auth 向导。

CLI 索引

在系统终端运行，不在 Hermes 会话里。权威来源是 官方 CLI Commands。

命令 什么时候用 备注
hermes / hermes --tui 开始聊天。TUI 是推荐界面。 --cli 强制经典 REPL；Ctrl+P 命令面板。
hermes setup --portal 最快路径：Nous 登录 + Tool Gateway。 也有 Full Setup 和 Blank Slate。
hermes model · hermes auth 加 provider、OAuth、改默认模型；管凭据池。模型保存后跟 reasoning effort 步。 OpenRouter：auth add openrouter --type oauth。不要和会话里的 /model、/login 搞混。
hermes -c / --resume 恢复最近或指定会话。 --in dir 先切目录再查会话。
hermes chat -q "…" · hermes -z 提问。TTY 上 -q 默认种交互会话；纯一次性用 -z / --oneshot。 -z --resume 可续跑同一会话。
hermes gateway setup|run|status 配置并运行 messaging gateway。 WSL 用 run，不要 start。list 看多 profile 网关。
hermes sessions … list / export / prune / pin / optimize / repair / recover。 recover 离线重建到新文件；gateway 停稳再修。0.21.3 写柄共享后，健康拓扑不再误报多写者。
hermes peer add|dm|run|status 注册对端 gateway，向对方 Bot Chat 发 DM / 长任务。 跨机 bot-to-bot 传输层。
hermes plugins 装/启停插件、memory provider、context engine；catalog 钉扎。 无子命令进入交互屏；search / pack install。
hermes tools 按平台开关 toolset。 单次会话也可用 --toolsets。
hermes skills browse|install 浏览 Skills Hub、安装 skill。 安装前会跑安全扫描。
hermes cron 持久定时任务；含 memory / continuity / monitor / notepad。 会话内心跳用 /heartbeat；时区按 IANA；cron doctor 查舰队健康。
hermes doctor [--fix] 配置、依赖、会话库健康。 gateway 在跑时勿 --fix；会区分结构损坏 vs FTS。
hermes config set … 改配置或密钥。 自动写入 yaml 或 .env。
hermes update 拉最新代码并重装依赖。 --check / --plan 预览，--backup 先快照；镜像安装拒绝原地更新。
hermes backup / import 整机搬家；默认保留最近 3 个 zip。 单 profile 用 profile export/import；*.db 按页导入，勿改 inode。
hermes secrets 外部密钥源（如 Bitwarden Secrets Manager）。 配合密码盲填 / egress。
hermes approvals 从审批历史挖 allowlist 提案。 危险命令 / 受保护文件写入相关。
hermes security audit 对 venv、插件依赖、钉扎 MCP 做 OSV 扫描。 不扫全局包。
hermes dashboard 用网页管配置、密钥、会话、cron、skills、MCP。 优先只读打开会话库；0.21.3 刷新 token 合并，远程 Desktop 醒来连刷不再踢会话。
hermes mcp · mcp login 管理 MCP server，或让 Hermes 自己当 MCP server；过期 OAuth 重授权。 refresh 绑定 issuer；Desktop 有每日重授权提醒。
hermes profile · -p name 多套隔离实例：不同模型、记忆、bot、state.db。 multiplex 下 served profile 全进网关；凭证/白名单/MCP 不串档。
hermes kanban 多 profile 协作看板。 promote 会拒未完成父任务。
hermes send --to telegram "…" 脚本/cron 往 messenger 发一条，不跑 agent。
hermes acp · desktop · serve 接到 ACP 编辑器；启动 Desktop；无头后端服务。 长驻 serve/dashboard 共享 state.db 写柄注册表，避免重复 writer。

常用 slash

在 CLI / TUI / 多数 messenger 里输入 /。已安装 skill 也会出现在这个菜单里。权威：Slash Commands。

命令 什么时候用 典型提示
/help · /palette 看可用命令；模糊命令面板（也可用 Ctrl+P）。选中只插入，不自动执行。 /palette
/login 会话内登 Nous。离回合：链接与码进会话，浏览器确认后生效。群聊会拒绝；Slack 用 /hermes login。 /login
/model 在已配置模型之间切换。无参数打开模糊搜索 picker；Desktop/TUI picker 可带 reasoning effort。 /model --global
/new [name] 开新会话。别名 /reset。加 now/-y 跳过确认。记忆快照在此刻重读。 /new my-experiment
/resume · /sessions 恢复或浏览会话。TUI 里 /sessions 是实时切换器。 /resume
/status 模型、profile、目录、token、reasoning、待审批、上下文占用 + 本地 Session recap。不打 LLM。 /status
/context [all] 上下文占用可视化。/context all 会列出 skill 和 toolset 成本。 /context all
/compress 手动压缩。/compress here 2 保留最近两轮原文。默认 lean-tail。 /compress here 2
/rollback 列出或恢复文件系统 checkpoint。 /rollback 1
/diff [session] 看工作区或本会话累计 diff。 /diff session --stat
/steer 不打断当前 tool loop；下一次 tool 结果后注入提醒。也可用于纠偏子代理航向。 /steer 先只改 auth 模块
/queue · /q 下一轮再问，不打断当前回复。 /q 接着写测试
/background · /btw 另开后台会话跑这件事，当前会话继续。 /btw 调研这个 API
/goal · /subgoal 跨 turn 追求一个目标，直到 judge 认为完成。 /goal 把 CI 修绿
/heartbeat 会话空闲时按间隔重新注入 prompt。最短 60s。 /heartbeat every 10m 检查部署
/refine 立刻跑记忆/skill 自改进，不必等回合结束。 /refine 把部署流程存成 skill
/yolo · /approvals 跳过或设置危险命令审批。 /approvals smart
/personality 会话级人格覆盖，不改 SOUL.md。 /personality none
/focus · /verbose · /statusbar 只显示最终回复；工具输出详细程度；状态栏（缓存命中/延迟等）。 /focus on
/plugins · /reload-mcp 会话里管插件；重载 MCP（CLI 侧）。OAuth 过期后需先 mcp login 再 reload。 /reload-mcp
/worktree new CLI only。会话中切到隔离 git worktree。 /worktree new fix-auth
/handoff <platform> CLI only。把当前会话交到 messenger，要求 gateway 已运行。 /handoff telegram
/plan 捆绑 skill：打开 plan mode，计划写到 .hermes/plans/。 /plan
使用习惯

先让一次普通聊天跑通，再叠加 gateway、Bot Mode、cron、MCP。改 SOUL.md / AGENTS.md 或刚写入的记忆，要新开会话才进入 system prompt。hermes model / hermes auth 负责加 provider 与 reasoning effort；/model 只切已配好的模型；/login 补登 Nous。多 profile 时每个 state.db 隔离——会话搜索不会也不应串档。gateway 在跑时不要对活动库做 doctor --fix 或拆开复制 WAL。Desktop 远程看板醒来连刷若仍被踢，确认已升到 v0.21.3。
