一次跑完整份 spec

在真实项目根目录中启动 Codex 或 Claude Code，然后先跑 $setup-matt-pocock-skills。不确定时用 $ask-matt。看不懂上一句用 $wait-what。grill → spec → tickets 尽量留在同一个上下文窗口；之后每个 $implement 从 ticket 重新开始，或者交给 $implement-spec 一次并发跑完（每个 ticket 一个全新上下文的 implementer，不要 fork）。派子 agent 的 skill 一律新开上下文。同一 harness、同一目录、到了阶段边界时，优先继续或 /compact，$handoff 只在上下文需要搬走时用。开 PR 时 agent 会自己套 $pr 模板。一轮编码收工后，在清上下文之前跑 $retro：先认清仓库已有的 lint/CI，再把机械 finding 建成 deterministic check，把真正需要判断的留给 CODING_STANDARDS.md。从 v1.2.x 升上来的项目，记得把 CONTEXT.md / CONTEXT-MAP.md 用 git mv 改成 GLOSSARY.md / GLOSSARY-MAP.md，否则 skills 读不到你的术语表。
